# Sen · araçların ve seviyen

> Bir kez doldur. Sistem her taramada önce bunu okur.
> En önemli sütun "gerçekten ne yapıyorum" sütunu. Aracın tamamına değil, senin dokunduğun kısma alternatif aranıyor.

## Teknik seviyen

Sistem kurulum ve bakım puanlarını buna göre kaydırır. Birini işaretle:

```
[ ] Hiç sunucu kurmadım, terminal beni korkutuyor.
[ ] Kopyala yapıştır komut çalıştırabilirim, hata çıkarsa takılırım.
[ ] Docker kurdum, ortam değişkeni ayarladım.
[ ] Sunucu yönetiyorum, ters vekil ve yedekleme benim işim.
```

## Sunucun var mı

```
var / yok:
varsa aylık ücreti:
varsa üstünde kaç şey çalışıyor:
```

Sunucun varsa yeni araçların maliyeti paylaşılır ve puanlar yükselir. Yoksa sistem sunucu kirasını hesaba katar.

## Araç listesi

Her satırı doldur. Kullanmadığın özellikleri yazma, sadece dokunduğun kısmı yaz.

| | | | |
| | | | |

**"Gerçekten ne yapıyorum" nasıl yazılır:**
- Kötü: "proje yönetimi"
- İyi: "haftalık yapılacaklar listesi tutuyorum, üç kişi görüyor, dosya eklemiyorum"

Bu fark, alternatifin uyup uymadığını belirleyen tek şey.
