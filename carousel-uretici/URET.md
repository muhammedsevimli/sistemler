# URET · Tek Komut

> Carousel istediğinde bu dosyayı açıp aşağıdaki komutu kopyala, `<konu>` yerine kendi konunu yaz.
> Claude Code `CLAUDE.md` sayesinde marka + ses + swipe + format dosyalarını zaten okuyacak.

## Komut (kopyala, konuyu değiştir)

```
şu konuda instagram carousel'ı çıkar: <konu>

kurallar:
- önce marka + ses + swipe + format dosyalarını okuduğunu tek satırla söyle.
- 3 farklı hook üret (dert açısı, sayı açısı, karşı görüş açısı). her biri kapak slaytı olabilir.
- sonra 7 slaytlık tam carousel yaz: kapak + 5 ara slayt + kapanış (CTA).
- her slaytın altına "görsel:" diye tek satır tasarım yönergesi ekle.
- 02-ses.md yasak kelimelerini kullanma, tonu koru.
- çıktıyı ciktilar/ klasörüne YYYY-AA-GG-konu.md olarak yaz.
- en sonda linkedin için hitap notu ver ("siz"e çevir).
```

## Kısa versiyon (acele edince)
```
şu konuda carousel çıkar: <konu>. format ve ses dosyalarına uy, 3 hook + 7 slayt, çıktıyı ciktilar'a yaz.
```

## Not
Konu ne kadar netse çıktı o kadar iyi. Kötü konu: "satış". İyi konu: "küçük işletme neden indirim yapmadan da satabilir".
